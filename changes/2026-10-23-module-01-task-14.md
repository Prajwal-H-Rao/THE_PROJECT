# 2026-10-23 — Module 01 task 14 — gateway image and proof

## Scope

Task 14 of NOVA module 01: build images for the services created so far.
The only service that exists without an image is the api-gateway. The two
template Dockerfiles and the queue-runner image already run multi-stage,
digest-pinned and non-root. The loop ran three rounds: negator A blocked
twice, the revisions folded both objections in, and both negators signed the
final set. One negator proved the whole build in a sandbox, including a live
standalone boot with health and a 401 unauth answer.

## Honest claims

- The scan asserts secret values, not env names. `NOVA_SESSION_SECRET`,
  `NOVA_SERVICE_JWT_SECRET`, `nova_session` and `nova_csrf` sit in the
  bundled source by design, so an env-name sentinel would fail the pristine
  build. Every local secret value in `.env.example` carries one of the two
  scanned prefixes.
- The CI proof builds in the runner only; local Docker is unavailable. The
  negation sandbox built the same image layout locally and served it.
- `test_images_run_non_root` stays satisfiable from the image: the standalone
  server answers the health endpoints and rejects an unauthenticated call.
