# 2026-10-23 — Module 01 task 17 — HTTPS edge

## Scope

Task 17 of NOVA module 01: add the public HTTPS edge. A reverse proxy terminates TLS and proxies to the api-gateway. The proof: an HTTPS request from outside reaches the gateway, and plain HTTP does not answer.

- New `nova/infra/edge/README.md`: documents the edge, networks, ports, and the CI verification.
