## Problem

Task 21.12 (module 21, P5): expose the MCP servers of the inbox, finance, trips, WhatsApp and Telegram services. Artifact: each service's `src/mcp/`. Acceptance test: "Each server lists only its own tools." Each service is a stub at this phase.

## Changes (test-first)

- Wrote test files first for all 4 services:
  - `nova/services/inbox-service/src/mcp/server.test.ts`
  - `nova/services/finance-service/src/mcp/server.test.ts`
  - `nova/services/trips-service/src/mcp/server.test.ts`
  - `nova/services/channels-service/src/mcp/server.test.ts`
  
  Each test asserts: `handleMCPCall` rejects calls without a service JWT (`error: "no service token provided"`), and rejects calls for tools not owned by this service (`tool_not_found`). Test-first confirmed: `tsc` fails with module-not-found for `./server.js` before implementation exists.

- Wrote `src/mcp/server.ts` for all 4 services — pure-stdlib-free TypeScript MCP server wrapper:
  - `handleMCPCall(rawCall, serviceJWT, audience, grantClient)` short-circuits on missing/empty service JWT before any policy evaluation
  - Loads the service-specific catalogue from `packages/contracts/mcp/catalogue/` (inbox.json, finance.json, trips.json, integrations.json)
  - Scopes the loaded catalogue to tools where `owning_service` matches the service — each server lists only its own tools
  - Delegates to `@nova/contracts/mcp/server`'s `validateAndAuthorizeCall` with the scoped catalogue
  - Imports types from `@nova/contracts/mcp/tool` (not `/server`)

- Catalogue mapping:
  - inbox-service → inbox.json (owning_service: inbox-service)
  - finance-service → finance.json (owning_service: finance-service)
  - trips-service → trips.json (owning_service: trips-service)
  - channels-service → integrations.json (owning_service: integrations-service → no tools match "channels-service", server lists 0 tools — valid stub)

- Layout registration: new `src/mcp/` directories under 4 services. `services/*` prefixes already in `EXTRA_DIRECTORY_PREFIXES`. Counts updated: EXPECTED_DIRECTORIES 187→192, EXPECTED_LEAVES 117→119 (`tree_checks.py`); all count phrases in `layout-diff.md` updated 187→192 / 117→119.
